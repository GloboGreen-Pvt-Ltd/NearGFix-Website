
# NearGFix Security Policy

## Supported Versions

NearGFix is developed and maintained by Globogreen System & Technology Private Limited.

| Version | Security Support |
|---------|------------------|
| Latest production release | Supported |
| Development and preview builds | Internal testing only |
| Older releases | Not supported |

## Reporting a Vulnerability

We take the security of NearGFix seriously.

If you discover a security vulnerability, please report it privately.

**Security Contact:** support@neargfix.com

You can also use GitHub's private vulnerability reporting feature:

https://github.com/GloboGreen-Pvt-Ltd/NearGFix-Website/security/advisories

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected pages, APIs, or components
- Potential security impact

Do not publicly disclose vulnerabilities before they have been reviewed.

## Security Practices

- HTTPS for production services
- Secure authentication and authorization
- Environment-based secret management
- Dependency vulnerability monitoring
- Restricted AWS IAM and S3 permissions
- Security review before production deployment

## Response

We aim to acknowledge security reports within 3 business days. Resolution times depend on severity and complexity.
